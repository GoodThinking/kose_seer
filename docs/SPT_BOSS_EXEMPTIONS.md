# SPT 原生机制豁免与边界

> 状态：本地实施与本轮验收完成，2026-11-02，未发布。原生服务端逐入口回放、奥尔德试炼客户端胜利和谱尼单宠入口均已验证。
> 配套[逐只设计](SPT_BOSS_DESIGN.md)与[迁移验收](SPT_BOSS_CUTOVER.md)。

## 豁免决定

按具体副本入口豁免谱尼七封印与真身、奥尔德六试炼与真身、菲尼克斯三影。共16个逻辑组、16个服务端入口，涉及8个非零SPT ID，另有8个零ID谱尼入口。保留它们现有属性、招式、封印解锁、血条、复活、回复、无限PP和原生特殊伤害规则，不在上面继续添加新属性机制。

豁免不表示保留上一轮六职。以下所有入口都撤掉旧协同职责登记、六人破阵、最后40%锁血、通用周期蓄力、通用留场压力及相关胜利检查。不得误把原生能量封印伤害阈值、生命封印回血、勇气试炼减伤和真身多命当作旧六职一并删除。

## 本轮验证边界

16个豁免入口与Boss表对应，菲尼克斯`extraLives=3`，四只普通双命各`extraLives=1`。最终配置的逐入口A/B自然战斗与真实控制器回放通过，证据为`design-acceptance-stable-roster.json`、`controller-acceptance-lock-fixed-{a,b}.json`。原生奥尔德力量试炼客户端10回合胜利，开场双攻+2、实际先手与8004入包均已观察；谱尼客户端只验证单宠入口及7000HP、双攻+2开场，首回合落败，不宣称谱尼UI通关。证据位于`outputs/spt-boss-cutover-20261102/`的`ui-evidence.json`及其引用文件，不等于穷尽所有原生技能边界。
