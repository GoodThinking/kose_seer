# BOSS 招牌特性设计（2026-11-19 用户确认）

用户反馈：除了几个原版特色 BOSS，其余都是「克制压制 + 同一段描述」，要求每个 BOSS 有独特特性，难度中等偏上。
用户确认了整套方向和分四批的顺序：早期 SPT → 训练师之门 → 暗黑武斗场 → 星系霸主。四批和两个剧情 BOSS 都已实现（未提交、未发布）。

## 原则

1. 一 BOSS 一规则，取自它自己的招牌技能和形象。
2. 删掉通用护体 `typeHomeTurf`（非克制 -32%、克制 +25%），属性克制只靠克制表。
3. 半血觉醒 `halfHpAwaken` 只留给机制本身需要二阶段的少数几个。
4. 不做 0 伤害硬锁；每条规则至少两种解法，不依赖某一只精灵。
5. 层数、倒计时、形态切换必须在战报里看得见。
6. 保留同生共死免疫、秒杀免疫；异常免疫按 BOSS 单独给。
7. 原版特色不动：蘑菇怪、钢牙鲨、里奥斯、尤纳斯、魔狮迪露、哈莫雷特、塔西亚、悠悠、盖亚、厄尔塞拉、巨型树妖、克拉尼特、菲尼克斯、谱尼九关、奥尔德七试炼。

## 实现位置

- 规则：`deploy/baseline/app/dist/GameServer/Game/Battle/BossSignatures.js`（`DEFS` 表，每个特性可实现 init/status/onSwitch/select/hit/incoming/outgoing/playerHit/bossActed/turnEnd）。
- 钩子：`BossSpecialRules.js`（DecorateBoss、EnterNextPhase、ModifyDamageToBoss、OnTurnEnd、SelectBossSkill）、`BattleTurnExecutor.js`（先后手、命中、出手后）、`BattleManager.js`（UpdateBattlePet 换精灵、SendBossNotice 下发提示）。
- 配置：`scripts/build-boss-signatures.cjs` 的 `BOSSES` 表，写入 `boss_abilities.json` 的 `mechanics.signature` 与 `hint`，并同步 SPT 面板源码 `SptPanel.as` 的 BOSSES 表。
- 战报提示：服务端 64006 包；客户端 `compat/client-patches/boss-notice/`（PetFightMsgManager、PetFightController），`scripts/build-boss-notice.cjs`。
- 回归：`scripts/test-boss-signatures.cjs <app>`（每个 signature id 必须有一条测试，缺了会失败）。
- 校准：`LAB_LEVEL=boss LAB_EV=0 LAB_CALIBRATE=30 LAB_POTIONS=12 node scripts/spt-boss-lab.cjs <app> <out.json> <map/param,...>`。`signature.might` 是 BOSS 攻击伤害百分比。实验室策略不懂机制，回合数偏长，只看胜率和阵亡数；目标是胜率 70~95%、平均阵亡 1~3。

## 第二批：训练师之门（已实现）

标定：普通门「同级、每项学习力 128」，实验室胜率 57~83%；勇者门「100 级、满学习力」，43~80%。改动前同条件下普通门有 5 个 0~3%，说明这批守卫本来就偏难，学习力 0 的队伍不是目标人群。

与下表设计的出入：
- 塔奇多克：挣脱后本回合和下回合不会再被缠（否则先制挣脱当回合就被重新缠上）。
- 加耶罗：浮空只来自浮空连击，第 1 回合起每 4 回合（勇者 3）放一次；被每次命中都刷新会让物理技能永久不可用。
- 岩锤怪：只有疯狂连锤碎甲，每 3 回合放一次，单次最多 -3；大地之锤每回合碎甲时伤害滚雪球，实验室 0%。
- 瓦尔普：递减下限 25%→40%。
- 佩吉克：电量 12（勇者 14），大招 4、中招 2、小招 1；瘫痪受伤 +60%（勇者 +50%）。
- 帕里斯：水之形态回血 4%（勇者 3%）、减伤 25%（勇者 35%），避免回血循环拖死。

## 第三批：暗黑武斗场（26，110/…，已实现）

配置在 `build-boss-signatures.cjs` 的 `DARK` 表，倍率在 `DARK_MIGHT`。去掉通用的 typeHomeTurf、darkErosion 光环（受击反震、每回合回血）、halfHpAwaken、开场强化；保留异常免疫 [1,2,3,5]、同生共死免疫、秒杀免疫，终阶保留两条命。

- 实验室不会主动换精灵，巴弗洛（镇魂歌）、迪普利德（束带拦换人只在真实换精灵入口生效）的倍率偏保守。

## 第四批：星系霸主（16，已实现）

配置在 `build-boss-signatures.cjs` 的 `STAR` 表，倍率在 `STAR_MIGHT`。去掉通用的 typeHomeTurf、领域光环（iceDomain）、halfHpAwaken、开场强化、闪避（dodgePercent）、低血必暴（lowHpCritPercent）；保留异常免疫 [1,2,3,5]（伊特除外）、同生共死免疫、秒杀免疫，罗德利斯保留两条命，布莱克保留单挑。剧情 BOSS 原来没有任何规则，只加 signature 和同生共死免疫，不加异常免疫。
没有新增钩子。

标定：「同级、每项学习力 128、六只、12 瓶药」30 场，胜率 73~100%、平均阵亡 1.0~2.9（`outputs/boss-signatures-20261119/lab-star/final.json`）。改动前同条件下塞维尔、冰洛伏特、巴斯特 0%，德拉萨 3%，布莱克、肯佩德 7%；该伊、伊特、迪符特、墨杜萨、亚伦斯和两个剧情 BOSS 100%。该伊倍率加到 247 仍全胜（阵亡 2.2），取 240；暗夜冰狐倍率一高平均阵亡就超过 4，保持 100。

与下表设计的出入：
- 塞维尔：只挡攻击技能的直接伤害，固定伤害仍然有效；力竭是直接倒下（判玩家胜）；期间击倒过精灵则回复 20% 体力继续战斗（原设计没写击倒后怎样）。
- 冰洛伏特：冻结用疲惫实现，它先手时当回合就无法行动，玩家先手时是下一回合。
- 罗德利斯：第一条命没有规则；自焚可以把第二条命烧死。
- 巴斯特：每 4 回合两套装甲各长回 1 层（原设计不回复，剥完 6 次后规则就没了）。
- 亚伦斯：读条 4→5 回合、打断门槛 1500→1200：实验室同级队伍开场先强化，4 回合内打不出 1500，每 4 回合必死一只。
- 伊特：体力 10000→8000，回血 500 起每回合 +100 改为 300 起、最多 800；无上限时实验室三分之二的对局 400 回合打不完。异常打断后回复量重置（原设计只说停止）。
- 卡修斯：「消强」判定为它出手前有强化、玩家出手后强化全没了。
- 德拉萨：双方的浩劫扣血都不致死。
- 迪符特：攻势按层数算伤害倍率（每层 +10%），不占能力等级，所以没有上限。

- 肯佩德：改为「每回合卷走出战精灵最高的一级强化转给自己，没有强化时吸取 1/10 体力」。原设计扣 PP：战斗中的 PP 每次出招都会写回玩家存档，扣掉的 PP 会留在存档里，客户端显示的 PP 也不会同步，玩家会点到 0 PP 的技能被拒绝。

## 已知遗留

- 实验室打法不懂机制（不会换精灵、爱用属性技能），倍率是粗调。佩吉克倍率在 170→200 之间胜率从 97% 掉到 37%，曲线很陡，取 170。

- 被冻住的回合玩家选的技能仍会扣 1 点 PP（与睡眠、麻痹同样的既有行为）。

## 实机后修复（2026-11-19）

- 补位换精灵时同一状态行出现两次：`drainNotices` 同一回合没有新事件、状态没变时不再下发。
- 塞维尔不灭意志期限到了、因精灵阵亡还没结算时，状态行误显示「已用尽」：改为「期限已到，本回合结束时结算」。
- 迪普利德：换上未被缠的精灵后状态行仍写「缠着」；被缠的精灵阵亡后要等旧期限过完才缠下一只。两处都改为核对 catchTime。
- SPT 面板奥尔德七行：按 sptId 同步各自的说明和等级体力；真身完整说明放不下，面板用短版（`build-boss-signatures.cjs` 的 `ALDER_PANEL`）。
