# SPT 逐只首领设计方案

> 状态：本地实施与本轮验收完成，2026-11-02，未上线。151入口302条逐设计路线、真实控制器和六类代表性原生界面已验证；未穷举全部培养成本、难度梯度和随机种子。
> 本地结果见[迁移验收清单](SPT_BOSS_CUTOVER.md)。本轮不继承旧任务自动上线授权。SPT109已按用户确认保留机制、拆分现有合法打法，不新增技能或Boss特例。

## 核心决定

首领难度来自本身属性、专属特性、招式与公开的反制窗口。删去六名不同队员登记职责、每宠35%输出份额、未破阵保护最后40%体力、通用留场压力与通用周期蓄力。换宠用于接招、解标记、保护PP和切换输出能力；不会成为全体首领统一的胜利计数。

允许合适精灵、配招与培养水平完成单通。满级克制精灵能击败入门首领，是养成收益。后期首领要求针对机制准备；平衡目标是减少同一个体、同一配招、同一招式无脑横扫，不以“任何单宠必须失败”作为验收条件，也不宣称能在设计阶段证明所有单宠组合都不能通关。

传统首领的硬属性白名单、非必中免伤、未中指定异常就无限复活、指定唯一精灵收尾，按逐只条目改为软防护、有限恢复或替代破防路线。已有原创首领保留各自主题，补清窗口和动作顺序；不会重新给49只原创首领套一层相同战阵。

## 强度梯度

| 档位 | 起始数值 | 机制复杂度与养成要求 |
|---|---|---|
| 入门 | 60级；2200或2640体力；里奥斯每命2200 | 1个主要机制；正常克制、回复或换招可解。高培养单通允许。 |
| 标准 | 逐只保留85级或100级本体值 | 1个核心机制，至少两条路线；鼓励合适属性或配招，不检查队伍人数。 |
| 进阶 | 通常100级；体力按条目 | 关联防护、强化或有限回复；准备消强、弱化、异常应对或两种攻击招式。 |
| 核心 | 100级；体力按条目 | 多拍动作或分段防线，反制发生在明确时点；用培养、配招和抗性接招，不加伤害配额。 |

## 统一结算语义

1. “回合”均指一个完整回合。预告下一回合的动作，必须在玩家提交下一步选择前展示。先手打断需要发生在首领实际执行前；慢速队另有承受或准备路线。
2. “有效直接攻击”须命中且原始伤害为正。自然属性无效、技能本身落空、被控未行动、无效果的属性技能，不冒充有效攻击或破甲。软护盾不改变本服自然属性免疫。
3. 本文普通直伤指物理、特殊技能的普通伤害。比例削血、固定伤害、持续伤害、反弹、秒杀按各自路径结算，不能一招重复套两份普通伤害或反伤。原有同生共死、瞬杀等专项抗性在未明确取消时保留，不扩成所有来源免疫。
4. “命中后”拆层或清标记，默认在本次对应命中结算后生效；本段先按旧层数减伤，后续命中段可受益。写明“每段”才允许多段拆多层，其余每行动最多触发一次。不得先用未命中攻击免费拆甲。
5. 普通SPT不再全异常免疫；正文明确的局部免疫才保留。拟将既有原创首领的控制保护用于这些普通SPT：实际被外来控制跳过一次行动后，获得下一完整回合控制抵抗；不限制中毒、烧伤、冻伤等持续伤害，也不把首领自我疲惫当外来控制。原生豁免副本继续自身规则。
6. 消强是清除正等级，弱化是实际降低等级。消强到0不能冒充防御降为负；降低失败不能触发破甲、灭火或打断。独立荆棘、流沙、契约等只按正文指定动作解除。
7. 普通SPT删除旧 `2010` 无限PP，按实际技能PP消耗。原生豁免的无限PP按原规则保留。49只原创首领保留已有有限撞击后备规则，最多35次；本轮不另外创造替代技能或追加行动。
8. 只给正文明确提到恢复的首领保留或设置恢复。传统条目写明各自全场次数与总量；没有恢复条目就不新增回血。原创首领保留既有预算：标准全场40%、单行动20%；进阶全场45%、单行动15%；核心全场40%、单行动10%，主动回复间隔至少4回合。原技能PP、禁疗、缺失体力及逐只次数限制仍同时生效，取最小允许值。
9. 删除旧六职的单次18%/14%/12%普通伤害上限，也撤销原创 `UniverseBossBudget.LIMITS.action` 对普通直接伤害的通用封顶，让爆发与窗口真实受益。既有比例削血、持续伤害、反伤和瞬杀专项保护单独保留；不把“撤单次直伤封顶”误做成取消全部防刷规则。
10. 传统SPT条目是目标被动的完整集合。未明示保留的旧随机免伤、无条件先制、全异常免疫、吸血等不得自动叠回；原技能自身效果与明确保留的专项抗性另行结算。
11. 普通双命仅保留原有一次复活。每命写明的护甲可重建；全场治疗池、次数和已用阈值不因复活、换宠而重复获得。形态换招按原流程设置新技能PP。失败、退出、重开或另一场战斗不共享本场标记。
